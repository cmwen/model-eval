# Code Generation Evaluation

**Cognitive Type**: Technical Capability

## Purpose

Tests the model's ability to write, understand, debug, and explain code across multiple programming languages.

## Test Categories

### 1. Code Writing
- Algorithm implementation
- Function creation
- Class design
- API integration

### 2. Code Debugging
- Bug identification
- Error explanation
- Fix suggestions
- Edge case detection

### 3. Code Explanation
- Line-by-line analysis
- Complexity assessment
- Documentation generation
- Architecture review

### 4. Code Translation
- Language conversion
- Framework migration
- API version updates

## Evaluation Metrics

| Metric | Description | Weight |
|--------|-------------|--------|
| **Correctness** | Code runs correctly | 40% |
| **Efficiency** | Time/space complexity | 20% |
| **Readability** | Clean, maintainable | 20% |
| **Best Practices** | Follows conventions | 20% |

## Supported Languages

- Python, JavaScript/TypeScript
- Java, C#, C++
- Go, Rust
- SQL, Shell/Bash

## Common Failure Modes

1. **Syntax Errors**: Invalid code
2. **Logic Bugs**: Incorrect behavior
3. **Security Issues**: Vulnerable code
4. **Outdated Patterns**: Deprecated APIs
