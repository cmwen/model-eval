# Multilingual Evaluation

**Cognitive Type**: Language Capability

## Purpose

Tests the model's ability to understand and generate content in multiple languages:
- Translation quality
- Cross-lingual understanding
- Language-specific nuances
- Code-switching handling

## Test Categories

### 1. Translation
- Direct translation
- Idiomatic expressions
- Technical terminology
- Literary translation

### 2. Multilingual Understanding
- Questions in various languages
- Cross-lingual information retrieval
- Multilingual summarization

### 3. Language Generation
- Native-sounding output
- Grammar correctness
- Cultural appropriateness
- Register/formality

### 4. Code-Switching
- Mixed language input
- Language detection
- Appropriate response language

## Supported Languages

| Tier | Languages |
|------|-----------|
| **Tier 1** | English, Spanish, French, German, Chinese, Japanese |
| **Tier 2** | Portuguese, Italian, Korean, Arabic, Russian, Hindi |
| **Tier 3** | Dutch, Polish, Turkish, Vietnamese, Thai, Indonesian |

## Evaluation Metrics

| Metric | Description | Weight |
|--------|-------------|--------|
| **BLEU Score** | Translation accuracy | 30% |
| **Fluency** | Natural sounding | 25% |
| **Adequacy** | Meaning preservation | 25% |
| **Grammar** | Correctness | 20% |
