# Web Tools Evaluation

**Cognitive Type**: Agent Capability

## Purpose

Tests the model's ability to interact with web-based tools:
- Search engines
- URL fetching
- Content extraction
- Web browsing simulation

## Test Categories

### 1. Search Query Formation
- Effective query construction
- Search operator usage
- Query refinement

### 2. URL Handling
- Valid URL construction
- Parameter handling
- Encoding requirements

### 3. Content Extraction
- Relevant information extraction
- Summarization of web content
- Source attribution

### 4. Multi-Step Web Tasks
- Research workflows
- Information aggregation
- Fact verification

## Evaluation Metrics

| Metric | Description | Weight |
|--------|-------------|--------|
| **Query Quality** | Effective search queries | 30% |
| **Relevance** | Finding pertinent info | 30% |
| **Accuracy** | Correct information | 25% |
| **Attribution** | Proper sourcing | 15% |

## Expected Behavior

- Form effective search queries
- Handle URLs correctly
- Extract relevant information
- Cite sources appropriately

## Common Failure Modes

1. **Vague Queries**: Ineffective searches
2. **URL Errors**: Malformed links
3. **Overconfidence**: Claiming without verification
4. **Source Confusion**: Mixing up sources
