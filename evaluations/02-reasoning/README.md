# Reasoning Evaluation

**Cognitive Type**: System 2 (Slow Thinking)

## Purpose

Tests the model's ability to perform complex reasoning, multi-step logic, and analytical thinking. These tasks require deliberate thought processes.

## Test Categories

### 1. Logical Reasoning
- Deductive reasoning
- Inductive reasoning
- Syllogisms
- Logical puzzles

### 2. Mathematical Reasoning
- Word problems
- Multi-step calculations
- Pattern recognition
- Algebraic thinking

### 3. Analytical Reasoning
- Cause and effect analysis
- Comparison and contrast
- Hypothesis evaluation
- Evidence synthesis

### 4. Common Sense Reasoning
- Physical world understanding
- Social situations
- Temporal reasoning

## Evaluation Metrics

| Metric | Description | Weight |
|--------|-------------|--------|
| **Correctness** | Final answer accuracy | 35% |
| **Reasoning Chain** | Valid logical steps | 35% |
| **Coherence** | Clear explanation | 20% |
| **Efficiency** | Concise reasoning path | 10% |

## Expected Behavior

- Step-by-step reasoning
- Clear logical connections
- Explicit assumptions stated
- Valid conclusions

## Common Failure Modes

1. **Reasoning Shortcuts**: Jumping to conclusions
2. **Logic Errors**: Invalid inferences
3. **Calculation Mistakes**: Math errors
4. **Context Loss**: Forgetting earlier steps
